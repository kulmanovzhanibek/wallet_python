# Карта этапов

Проект собирается по плану из ТЗ (раздел 13). Ниже — что уже сделано, что
делается сейчас и что осталось. Каждый этап заканчивается зелёными
`make lint` и `make test`, чтобы код всегда был в рабочем состоянии.

## Этап 1 — каркас ✅

| Файл | Зачем нужен |
|------|-------------|
| `pyproject.toml` | зависимости (uv), правила ruff, mypy `--strict`, pytest, coverage |
| `app/core/config.py` | все настройки из переменных окружения, падение на старте без обязательных |
| `app/core/logging.py` | JSON-логи structlog, `request_id` / `update_id`, вырезание секретов |
| `app/infra/db.py` | один engine и фабрика сессий на процесс + `SELECT 1` для `/ready` |
| `app/infra/redis.py` | один Redis-клиент на процесс + `PING` для `/ready` |
| `app/domain/models.py` | доменные сущности (dataclass), без SQLAlchemy и aiogram |
| `app/domain/money.py` | `Decimal`, банковское округление, форматирование сумм |
| `app/domain/periods.py` | границы дня/недели/месяца в часовом поясе пользователя |
| `docker-compose.yml` | Postgres 16 и Redis 7 для локальной разработки |
| `Makefile`, `.pre-commit-config.yaml`, `.github/workflows/ci.yml` | рутина и проверки |
| `tests/unit/` | 109 тестов: деньги, периоды, конфиг, логи |
